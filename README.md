# まるのひみつアドベンチャー

小学6年生が、円の面積・おうぎ形・組み合わせた図形を、触る・動かす・当てる・そろえる操作から学ぶブラウザ教材です。苦手な児童も1画面1判断で進め、慣れてきたら「図形の見分け→考え方→式→答え」の詳しい問題へ挑戦できます。

## 主な機能

- 「まるのひみつ島」を育てる、学習内容と結び付いた短いごほうび
- ピザをタップして自動で並べる「ピザこうじょう」
- 6種類のケーキを色塗りし、分数から中心角へつなぐ「ケーキショップ」
- 道具選び→記号選び→式カードの順で進む「ずけいレスキュー」
- レベル3として従来の詳しい4段階問題を残した「チャレンジタワー」
- 文章で止めず、図の変化と短い言葉で返す誤答フィードバック
- 10ステージ・各10問、合計100問の固定問題（葉っぱ型・まがたま型を含む）
- 円・おうぎ形・逆算・弧・ドーナツ型のランダム生成
- 安全な式パーサーによる同値な式の判定（`eval`不使用）
- 5段階ヒント、3.14計算支援、約分の段階表示
- localStorageによる進捗・設定・図形カード・島の成長の保存
- `#test`で実行できるブラウザテスト

外部API、APIキー、サーバー、データベース、外部フォント、外部画像、外部音声は使用しません。個人情報の入力もありません。

## ファイル構成

```text
index.html
css/                 見た目・配置・部品・動き・レスポンシブ
js/
  components/        再利用するUI
  data/              固定問題とステージ
  diagrams/          SVG描画
  generators/        ランダム問題生成
  services/          問題・進捗・カード・音
  tests/             ブラウザテスト
  utils/             計算・分数・式判定・表示
  views/             各画面
docs/                追加・設計・手動確認の資料
```

## GitHub Pagesで公開する

1. リポジトリの `Settings` → `Pages` を開きます。
2. `Deploy from a branch` を選びます。
3. `main` と `/ (root)` を選んで保存します。
4. 表示されたURLを開きます。

ビルドは不要です。ES Modulesを使うため、ローカル確認ではファイルを直接ダブルクリックせず、VS Code Live Serverや `python -m http.server 8000` などの静的サーバーを使います。

## 問題や図形を追加する

- 固定問題：`js/data/*Problems.js`
- ステージ名：`js/data/stages.js`
- 図形：`js/diagrams/` に描画関数を追加し、`composite.js` に登録
- 自動生成：`js/generators/` に生成器を追加し、`problemService.js` に登録

詳しい例は [問題追加ガイド](docs/problem-data-guide.md) を参照してください。

## 保存データ

キーは `circleAdventureProgress`、現在のバージョンは1です。ステージ別の挑戦数・正解数・初回正解・ヒントなし正解・ヒント利用数、間違えた問題ID、苦手タグ、連続正解、設定、図形カード、最後の画面を保存します。破損データは初期状態に復旧し、バージョン違いは移行関数を通します。

## テスト

公開URLの末尾に `#test` を付けるか、設定画面の「自動テストを開く」を押します。成功・失敗・期待値・実際の値が表示されます。
