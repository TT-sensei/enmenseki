# 円の面積（enmenseki）

小学6年生 算数「円の面積」の学習アプリです。円を細かく等分して並べ替えると長方形に近づく体験（へんしんラボ）を中心に、「半径 × 半径 × 3.14」の理由と使い方を学びます。

公開ページ： https://tt-sensei.github.io/enmenseki/

## 構成

- `index.html`：画面の骨組み（単一ページアプリ）
- `style.css`：見た目（コーラルをテーマ色にした、白い角丸カードのデザイン）
- `js/app.js`：画面遷移・進行・記録・バッジなどの処理
- `js/lab.js`：へんしんラボ（扇形の並べ替えアニメーション）
- `js/data.js`：固定問題（組み合わせ図形14問・文章題8問）と、パラメータ生成の問題
- `js/diagrams.js`：問題図のSVG描画

外部API・外部フォント・バックエンドは使いません。演出と音は TT-sensei の共通基盤（edu-effects / sounds-recipe-）、キャラクター画像は navi-character-、バッジ画像は edu-assets を参照します。記録は localStorage にだけ保存されます。

## 学習内容

### へんしんラボ（単元の心臓）
円を 8・12・18・24・36 等分した扇形を、上下交互に並べ替える操作。細かく分けるほど長方形に近づき、たて＝半径、横＝円周の半分（半径 × 3.14）であることから、円の面積＝半径 × 半径 × 3.14 が導かれることを確かめます。半径を変えて数値でも確認できます。

### 練習（1回10問・4択）
考える順序で5種類＋まぜまぜ。

1. もとめ方：半径から面積を求める
2. 直径から：直径を半径に直してから求める
3. おうぎ形：中心角と分数で考える
4. 組み合わせ：半円・ドーナツ型・葉っぱ型・長方形との組み合わせなど（固定14問）
5. 逆算と文章題：面積から半径を考える、円周と面積の使い分け、文章題（固定8問＋生成）

答えるとその場で解説が出ます。選択肢には典型的な間違い（直径を半径として使う、円周の公式と混同する、半円で ÷2 を忘れる等）を織り込み、間違えた場合は選んだ答えの「まちがいポイント」を示します。

### 記録と再挑戦
間違えた問題は端末内に記録され、再挑戦して正解すると記録から消えます（克服）。学習の記録画面では、解いた数・正解数・種類別の記録と、努力や達成で集まるバッジ10種を確認できます。

## 計算ルール

- 円周率は 3.14 を使います。
- 答えは小数第2位までで割り切れる数値の組み合わせだけを出題します。
- 問題の答えは、検証スクリプト（`verify/check.mjs`）で全件再計算して照合しています。

## 保存データ

- 保存キー：`enmenseki.v2`（解いた数・正解数・まちがえた問題・バッジ・音の設定）
- 旧版「まるのひみつ島」の保存データとは互換性がありません（作り直しに伴い、新しいキーで開始します）。
